# Data governance

Before any acquisition or tokenizer/model training, record each source's owner,
immutable revision, license evidence, attribution, permitted use, retention,
privacy risks, PII handling, and checksum in a manifest. A valid SPDX string is
not sufficient proof of rights. Separate research and commercial-clean data
policies and do not mix sources with incompatible terms.

Use the acquisition CLI only after local review. This implementation includes
license and provenance checks but cannot determine legal permission, consent,
student-record obligations, or whether a source contains restricted material.
No dataset was downloaded or processed here.
