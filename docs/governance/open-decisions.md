# Open governance decisions

The software is ready to accept governed data, but no training data or weights
are included. Before training or distribution, the project owners still need
to decide:

- Whether synthetic training examples generated by other models are permitted
  (plan decision D8), and which generators/licenses are acceptable.
- Urdu priority and evaluation commitments for the 100M encoder (D10).
- Which research or commercial-clean distribution mode is intended, with legal
  review of attribution, share-alike, and web-text copyright concerns (D9).
- Written authorization for course documents and student materials.
- Compute budget, annotator capacity, and the sealed evaluation set owners.

No code in this repository resolves those policy choices by silently changing
the plan. The manifest/license gates are configurable so the selected policy can
be recorded for each run.
