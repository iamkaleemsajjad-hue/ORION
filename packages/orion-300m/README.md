# orion-300m

Independent ORION-300M causal language-model software with grouped-query attention, generation utilities, context-grounding interfaces, and training objectives.

This distribution does not contain trained ORION weights or a production-trained shared tokenizer. SDK loading fails with a useful error until compatible local artifacts are supplied. Citation markers identify supplied source references; they are not independent proof that generated claims are supported.

Install the shared dependencies declared in package metadata and consult the ORION-300M SDK and training guides for supported interfaces.
