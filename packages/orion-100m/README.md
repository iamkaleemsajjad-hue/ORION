# orion-100m

Independent ORION-100M encoder software for document representations, classification heads, course matching, metadata extraction, and training objectives.

This distribution does not contain trained ORION weights or a production-trained shared tokenizer. SDK loading fails with a useful error until compatible local artifacts are supplied. It does not require MADAD; host integration belongs in the separate optional adapter.

Install the shared dependencies declared in package metadata and consult the ORION-100M SDK and training guides for supported interfaces.
